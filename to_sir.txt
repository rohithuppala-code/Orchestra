1. EXECUTIVE SUMMARY & RESEARCH OBJECTIVE
--------------------------------------------------------------------------------
Most current multi-agent systems (e.g., AutoGen, MetaGPT, ChatDev) hardcode
fixed human roles in advance (such as "You are the Manager" or "You are the Coder").

Our research studies TRUE EMERGENT SELF-ORGANIZATION:
- We place autonomous AI agents into partitioned environments with ZERO pre-assigned
  roles and symmetric capabilities.
- We study how communication networks, spontaneous leadership (division of labor),
  and structural hierarchies emerge naturally over rounds of problem-solving.
- We introduce novel mathematical metrics borrowed from economics (Gini Specialization)
  and network science (Jaccard Structural Drift) to scientifically quantify these societies.
- We test organizational resilience by deliberately crashing agents midway to measure
  how the remaining society re-organizes and adapts.

--------------------------------------------------------------------------------
2. BENCHMARK SUITE: 30 TASKS ACROSS 3 PARADIGMS
--------------------------------------------------------------------------------
We evaluate agent populations across 30 distinct benchmark tasks divided into
3 real-world computational paradigms:

1. Paradigm I: Cross-Silo Aggregation (Tasks 1 to 10)
   - Real-World Analogy: Distributed hospitals or banks computing global totals
     without revealing raw private patient/financial records.
   - Example: Sum, Global Maximum, Median, Threshold Count.

2. Paradigm II: Spatial Mesh & Neighborhood Routing (Tasks 11 to 20)
   - Real-World Analogy: Logistics warehouses and delivery sensors matching local
     inventory across neighboring boundary zones.
   - Example: Graph shortest paths, boundary value reconciliation, spatial clusters.

3. Paradigm III: Global Shuffle & Distributed Joins (Tasks 21 to 30)
   - Real-World Analogy: Cross-referencing two distinct relational databases
     (e.g., matching customer profiles in Silo A with credit card logs in Silo B).
   - Example: Distributed relational join, key-value aggregation, multi-hop lookups.

--------------------------------------------------------------------------------
3. THREE COMMUNICATION PROTOCOLS (HOW AGENTS TALK)
--------------------------------------------------------------------------------
For every task, we examine how communication constraints alter organization:

1. Direct Messaging (P2P / "msg"):
   - Analogy: Private phone calls.
   - Agents send point-to-point private messages directly to specific peers.

2. Room Broadcasting ("broadcast"):
   - Analogy: Public megaphone.
   - Any message sent is simultaneously heard by every agent in the society.

3. Shared File System ("sfs"):
   - Analogy: Shared office whiteboard / blackboard.
   - Agents communicate purely by reading and writing structured notes to a
     shared blackboard file.

--------------------------------------------------------------------------------
4. HOW A SINGLE EXPERIMENT RUNS (THE 3 CORE PHASES)
--------------------------------------------------------------------------------
Every experimental run operates round-by-round across 3 sequential phases:

Example: Task I-01 (Finding the Global Maximum across 2 agents)
- Problem: The true global maximum across both databases must be found.
  Agent 0 has a private list with maximum = 827.
  Agent 1 has a private list with maximum = 780.
  Neither agent knows the other's numbers.

- Round 1 (Local Analysis & Outreach):
  Both agents query their local databases.
  Agent 0 calculates its local max (827) and messages Agent 1:
  "My local maximum is 827. What is yours?"
  Agent 1 calculates its local max (780) and messages Agent 0:
  "My local maximum is 780. What is yours?"

- Round 2 (Reading & Decision):
  Agent 0 reads 780 and deduces: 827 > 780, so Global Max = 827.
  Agent 1 reads 827 and deduces: 827 > 780, so Global Max = 827.

- Round 3 (Consensus & Verification):
  Both agents execute the submit_result(827) action.
  The engine verifies submissions against ground truth -> 100% Success.

6. NOVEL EVALUATION METRICS (BEYOND ACCURACY)
--------------------------------------------------------------------------------
While existing papers only measure whether an answer was right or wrong,
ORCHESTRA automatically measures 7 comprehensive layers of organizational dynamics:

1. Task Performance: Success Rate (S), Partial Correctness (P), Token Cost (C).
2. Gini Specialization Index (Gini_out / Gini_in):
   - Measures economic division of labor.
   - Gini = 0.0 means perfect equality (all agents talk equally).
   - High Gini (e.g. > 0.6) proves spontaneous emergence of a "Hub / Coordinator"
     who controls the communication flow.
3. Communication Redundancy Ratio:
   - (Actual Messages Exchanged) / (Theoretical Minimum Messages Required).
   - Quantifies communication waste and coordination efficiency per task.
4. Network Topology Metrics:
   - Communication Density (D), Reciprocity (R), Clustering Coefficient, and Diameter.
5. Jaccard Structural Drift (J):
   - Measures how the communication network rewires itself round-by-round.
6. Fault-Tolerance & Recovery Rate:
   - Measures whether the surviving agents detect a peer crash and salvage
     partial answers, avoiding deadlock.
7. Human-in-the-Loop (HITL) Boundary Oversight:
   - Automatically detects monopolies (an agent dominating >85% of traffic),
     isolation (an agent left out), or stagnation loops.

8. MULTI-AGENT BASELINE METHODOLOGIES & COMPARATIVE SUITE
================================================================================
To benchmark ORCHESTRA against established literature for our paper submission,
we have implemented 6 foundational and state-of-the-art baselines under a
completely isolated, modular package (`baselines/`):

1. Independent Agents (No Communication / Majority Vote Ensemble)
   - Citation: Wang et al. (ICLR 2023)
   - Mechanism: Inter-agent messaging is blocked; agents solve independently from
     their private data shards. Collective answer is synthesized via majority vote.

2. Fully Connected Broadcast (Flat Multi-Agent Debate)
   - Citation: Qian et al. (ChatDev, ACL 2024); Du et al. (ICML 2023)
   - Mechanism: Unconstrained all-to-all broadcast across every round.

3. Random Topology (Erdos-Renyi Random Graph, p=0.5)
   - Citation: Erdos & Renyi (1960); Watts & Strogatz (1998)
   - Mechanism: Communication links form randomly with 50% probability each round.
     Serves as an essential ablation proving structured organization is required.

4. Central Coordinator (Star Hub-and-Spoke Architecture)
   - Citation: Wu et al. (AutoGen, ICLR 2024)
   - Mechanism: Agent 0 is designated as the sole hub. Worker-to-worker messages
     are dropped; all traffic bottlenecks through Agent 0.

5. Hierarchical Coordinator (Multi-Tier Tree / Chain of Command)
   - Citation: Wang et al. (MacNet, ICLR 2024 / Neural Networks 2025)
   - Mechanism: Strict multi-tier tree hierarchy (Executive -> Division Leads -> Workers).
     Skip-level and cross-branch communications are restricted.

6. Fixed Predefined Roles (Static Prompt Specialization)
   - Citation: Hong et al. (MetaGPT, ICLR 2024 Oral)
   - Mechanism: Explicit role prompts injected upfront (Agent 0 = Chief Architect;
     Agents 1..N = Subordinate Specialists).

7. ORCHESTRA (Our Proposed Framework)
   - Mechanism: Emergent dynamic self-organization with zero hardcoded roles
     and spontaneous division of labor.
