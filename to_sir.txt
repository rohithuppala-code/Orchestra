--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & RESEARCH OBJECTIVE
--------------------------------------------------------------------------------
Most current multi-agent systems (e.g., AutoGen, MetaGPT, ChatDev) hardcode
fixed human roles in advance (such as "You are the Manager" or "You are the Coder").

Our research studies TRUE EMERGENT SELF-ORGANIZATION:
- We place autonomous AI agents into partitioned environments with ZERO pre-assigned
  roles and symmetric capabilities.
- We study how communication networks, spontaneous leadership (division of labor),
  and structural hierarchies emerge naturally over rounds of problem-solving.
- We introduce novel mathematical metrics borrowed from economics (Gini Specialization)
  and network science (Jaccard Structural Drift) to scientifically quantify these societies.
- We test organizational resilience by deliberately crashing agents midway (Agent Dropout)
  to measure how the remaining society re-organizes and adapts.

--------------------------------------------------------------------------------
2. STRATIFIED BENCHMARK SUITE: 15 TASKS ACROSS 3 PARADIGMS
--------------------------------------------------------------------------------
Grounded in SILO-BENCH (ACL 2026), we evaluate agent populations across a balanced,
stratified 15-task benchmark (5 tasks evenly spanning easy, medium, and hard
difficulty per computational paradigm):

1. Paradigm I: Cross-Silo Aggregation (5 Tasks)
   - Tasks: I-01 (Global Max), I-04 (Any Match), I-07 (Average Value),
            I-09 (Top-K Select), I-10 (Standard Deviation)
   - Real-World Analogy: Distributed hospitals or banks computing global statistics
     without revealing raw private patient/financial records.

2. Paradigm II: Spatial Mesh & Neighborhood Routing (5 Tasks)
   - Tasks: II-11 (Prefix Sum), II-14 (1D Life Game), II-15 (Pattern Search),
            II-17 (Diff Array), II-20 (Pipeline Hash)
   - Real-World Analogy: Logistics warehouses and delivery sensors reconciling
     state across neighboring boundary zones.

3. Paradigm III: Global Shuffle & Distributed Joins (5 Tasks)
   - Tasks: III-21 (Distributed Sort), III-23 (Graph Components), III-25 (K-Means Iteration),
            III-28 (PageRank Step), III-30 (Matrix Multiply)
   - Real-World Analogy: Cross-referencing distributed relational datasets,
     global graph structure, and iterative matrix/clustering state.

--------------------------------------------------------------------------------
3. COMMUNICATION PROTOCOLS EVALUATED
--------------------------------------------------------------------------------
We evaluate the two primary agent communication substrates used in our cross-baseline
comparison:

1. Direct Messaging (P2P / "msg") -> ORCHESTRA (Our Proposed Method):
   - Analogy: Private peer-to-peer channels.
   - Agents choose *who* to message dynamically, enabling spontaneous hub emergence
     and sparse, token-efficient coordination.

2. Room Broadcasting ("broadcast") -> Flat Broadcast Debate Baseline:
   - Analogy: Public megaphone (complete all-to-all mesh).
   - Every message sent is simultaneously seen by all agents in the society.

*(Note: Shared File System "sfs" is excluded from this execution matrix because it
lacks peer-to-peer message edges and is not evaluated in cross-baseline Tables 1-4.)*

--------------------------------------------------------------------------------
4. HOW A SINGLE EXPERIMENT RUNS (THE 3 CORE PHASES)
--------------------------------------------------------------------------------
Every experimental run operates round-by-round across 3 sequential phases:

Example: Task I-01 (Finding the Global Maximum across 2 agents)
- Problem: Agent 0 holds a private list (max = 827); Agent 1 holds a private list
  (max = 780). Neither agent sees the other's raw records.
- Round 1 (Local Analysis & Outreach): Both compute local maxima and message peers.
- Round 2 (Reading & Synthesis): Agents compare received values and deduce Global Max = 827.
- Round 3 (Consensus & Verification): Agents execute submit_result(827); SILO-BENCH
  validates against ground truth -> 100% Success.

6. NOVEL EVALUATION METRICS (BEYOND ACCURACY)
--------------------------------------------------------------------------------
ORCHESTRA automatically instruments 7 layers of organizational and task metrics:

1. Task Performance: Success Rate (S), Partial Correctness (P), Token Cost (C).
2. Gini Specialization Index (Gini_out / Gini_in):
   - Gini = 0.0 denotes egalitarian communication; high Gini proves spontaneous
     emergence of coordinator hubs without role prompts.
3. Network Topology Metrics: Communication Density (D), Reciprocity, Clustering, Diameter.
4. Jaccard Structural Drift (J): Measures round-by-round network rewiring.
5. Fault-Tolerance & Resilience Delta: Performance retention under Round-2 Agent Dropout.
6. Human-in-the-Loop (HITL) Boundary Oversight: Logs monopolization (>85%), isolation,
   and stagnation loops in real time.

--------------------------------------------------------------------------------
7. MULTI-AGENT BASELINE SUITE (5 DISTINCT PARADIGMS IN TABLES 1-4)
--------------------------------------------------------------------------------
1. Independent Agents (No Communication) — Wang et al. (ICLR 2023)
   - All cross-agent messaging blocked; evaluates local silo performance alone.
2. Fully Connected Broadcast (Flat Debate) — Qian et al. (ACL 2024); Du et al. (ICML 2023)
   - Unconstrained all-to-all broadcast (sourced cleanly from ORCHESTRA broadcast runs).
3. Central Coordinator (Star Hub-and-Spoke) — Wu et al. (AutoGen, ICLR 2024)
   - Agent 0 designated sole hub; worker-to-worker messages filtered out.
4. Hierarchical Coordinator (Static Multi-Tier Tree) — Wang et al. (MacNet, ICLR 2024/2025)
   - Strict tree chain-of-command across divisions; skip-level messages blocked.
5. ORCHESTRA (Our Proposed Framework) — This Work
   - Zero predefined roles, dynamic P2P messaging ("msg"), emergent specialization,
     and adaptive rewiring under agent failure.
